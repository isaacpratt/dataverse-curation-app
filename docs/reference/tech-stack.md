# Tech stack reference

Exact versions for the Python runtime dependencies, the development toolchain and the two toolchain pins that live outside `pyproject.toml`. `pyproject.toml` declares floors; `uv.lock` records the resolved versions; `.python-version` and `global.json` pin the Python interpreter and the .NET SDK used to build releases.

The table below is generated by `poe docs-gen-tech-stack` from those four files. Do not edit the marked block. A dependency or lock change is incomplete until the block is regenerated; `poe docs-gen-tech-stack-check`, `poe docs-check` and pytest refuse a stale one.

For the toolchain decisions behind these choices, see [ADR 0001](https://github.com/isaacpratt/dataverse-curation-app/blob/master/docs/adr/0001-uv-poe-precommit.md). For how each tool is used, see [Run the gates](../how-to/run-the-gates.md) and [Package and release](../how-to/package-and-release.md). For the bundled fonts and their licences, see the font README in `ui/assets/fonts/`.
