Open decisions

Needs a call before work starts:
  • Delete ui/assets/32x32.png? — superseded by 16x16.png (dashboard/taskbar) and docent-mark.ico (exe); no code references it anymore. Trivial cleanup once confirmed.
  • 25k-row paint benchmark — the painting window (2,000 rows) is a safe default, not a measured optimum. Benchmark _apply_filter() + sort + keystroke at 25k synthetic rows and raise the cap if the real cost is acceptable. The windowing code makes this a one-line change.
  • Enrichment cap tuning — 200 rows per refresh is a starting point, not a measured optimum. It trades dashboard completeness against N version fetches per refresh; raise it if curators want sizes on every row, lower it for very large collections.
  • Auth-fallback policy for enrichment — a dataset whose every version is refused is currently skipped silently (the row stays thin). A curator might rather see “size unavailable” than a blank cell.
