Dataverse integration

Native/Search API only — no PostgreSQL/Solr. All endpoints are relative to config.dataverse.base_url; auth via X-Dataverse-key.

Authentication

  • Header X-Dataverse-key: <api_token>. Search with a token returns drafts; without, only published.
  • Token lives in config.json / Settings. Presets include Borealis Demo — demo.borealisdata.ca → https://demo.borealisdata.ca. On 401 a selectable dialog points at Settings; the token is never stored in SQLite and never leaves in diagnostics copies.

Review-state discovery

Search docs need draft-aware reading (search_item_state): a published-plus-new-draft dataset can surface as RELEASED yet carry “Draft” in publicationStatuses. Draft/review markers anywhere win; duplicate PIDs keep the draft row — otherwise in-progress versions vanish from draft filtering.

Download flow (approval-gated)

1Quotequote(pid) → count + bytes (original size for tabular). No bytes moved.
→
2ApproveDownloadApprovalDialog with large-dataset warning. Nothing downloads until approved.
→
3StreamTo _bundle.zip.part, atomic rename; draft → latest → unversioned, 3× retry per version.
→
4StageAtomic unzip (files.new/ → swap), zip-slip guard, originals fetched, .tab removed (originals-only).
→
5Verifyverify() → (ok, problems, warnings): originals by size, rest by checksum. Previous stage survives partial failure.

Version comparison

MetadataWorker calls compare_versions(pid) alongside the metadata fetch; parse_version_compare normalizes the DatasetVersionDifference shape. The “Changes since publication” card renders a Field | Previous (vX) | New (Draft) table plus a color-coded file list (added green, removed red, replaced amber, metadata blue) with a vX → Draft · N change(s) summary. First versions show “no published version to compare against”; identical drafts show “no changes”.

Live-verified against https://demo.borealisdata.ca: version → Borealis; search subtree=mcmaster → 10 + 3 = 13 paginated; dataset lookup → citation title OK; versions → 23 files; bundle → 358 477 bytes streamed and unzipped. Empty alias and :root return the whole repo; root alias is dv.
