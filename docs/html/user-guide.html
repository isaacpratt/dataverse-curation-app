First run

  1. Launch (dist/curation-app-lite.exe or python main.py). With no config.json, the Settings page opens automatically.
  2. Choose the Dataverse: preset (Borealis Demo or Custom…), Base URL (e.g. https://demo.borealisdata.ca), API token (blank = public-only; drafts need a token), Collection alias (e.g. mcmaster; empty = whole repo; root alias on the demo is dv), Workspace folder. Test connection hits GET /api/info/version before saving.
  3. Extensions tab: per-package Install/Uninstall with sizes for optional curation libraries, plus Tesseract (OCR) and ExifTool paths.
  4. Save → the dashboard loads. Switch instances anytime via top-nav Settings (Ctrl+,); ? opens About. Headless runs ignore --dataverse/--config (local staged directory only).

Dashboard (curation queue)

Lists datasets from paginated Search (100/page, up to 1000). All 12 columns are sortable (numeric/date-aware), draggable, resizable with visible dividers, and togglable via Columns…. First paint auto-fits content (proportionally downscaled on overflow — the queue has no horizontal scrollbar); dragging any edge locks your widths; Columns… → Reset columns && sorting restores defaults. Status and Curation Label render as plain text.

Filter bar: free-text search + Status (All / Draft unsubmitted / Published / In Review / Deaccessioned) + Curation label (instance set + No label) + Collection combos. The queue is cached per instance+collection (dashboard_cache.json): instant paint on open, background refresh reports only what changed (N new, M updated, K removed / No changes). Double-click (or Enter) opens a dataset; F5 refreshes; Escape clears search.

Curating a dataset

1Review metadataAuto-loads on open (MetadataWorker); Load metadata re-fetches without downloading. Change the profile (McMaster/Minimal/custom) to re-evaluate instantly.
→
2Review changesVersion log: all versions + Previous vX → New Draft field diffs + added/removed/replaced files. First submissions show “Initial draft”.
→
3DownloadDownload All quotes count + size first (original size for tabular); fully-staged skips verified; approval dialog guards large sets; tabular originals replace .tab.
→
4Run checksRun checks dispatches every file (CheckWorker, indeterminate progress + per-file label). Without staged files it asks you to download first.
→
5InspectManifest tree folder › file › check (Clean / Warning / Error / Skipped / No automated check); files with issues auto-expand; filter by text + status combo; click for full message + details.
→
6ExportExport reports… writes *_report.json + *_report.md side-by-side (JSON canonical). Without a report it asks you to run checks first.
→
7RespondResponse tab assembles standard text per incomplete rule + failed check: uncheck to drop, edit freely (autosaved to response_draft.md), Regenerate / Copy / Export (logged as response_exported).

Notes on checks

  • Lite build covers JPG/PNG/PDF/XML/XLSX/TIFF offline (Pillow, pypdf, lxml, openpyxl, tifffile, chardet) + stdlib image-header fallback. Only heavy binary libs (pyreadstat, netCDF4, h5py, scipy) need the full build — run dist/curation-app-full/curation-app-full.exe directly for SPSS/SAS/Stata/NetCDF/HDF5/MAT. Missing libs report Missing … as warnings, never failures.
  • OCR and deep exif are optional: without tesseract/exiftool they report “not executed”.
  • Parity with the R inspectors is held by 198 tests (pytest --collect-only -q for the live count). Semantics: checks reference.

Log and troubleshooting

The Log stack page (nav Log button or Ctrl+L) shows every Dataverse request (GET <url> → <status> (<ms>) <summary>, local-time stamps) with INAV-style highlighting. Search log… filters (match counts in the tooltip), ● Live pauses/resumes (buffered lines catch up), plus Clear and hide. All error dialogs are selectable for pasting tracebacks.

Headless mode

python main.py --headless <staged_dir> --out report.json
python main.py --headless <staged_dir> --out report.json --persistent-id doi:10.5072/FK2/EXAMPLE
python main.py --headless <staged_dir> --out report.json --format both --persistent-id doi:10.5072/FK2/EXAMPLE

Same engine/runner.py:run_report without the GUI. --format json|md|both (default json). --dataverse/--config are GUI-only and rejected here. Exit codes: 0 clean, 1 error-level findings, 2 usage/IO failure.
