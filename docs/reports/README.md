# Historical reports

Dated reports kept for the record, outside the `docs/html/` documentation
set. They describe a point in time; they are not maintained and they do not
state the current plan.

| Report | What it records |
| --- | --- |
| `proposal-top10-dataset-review.html` | The 2026-11 dataset-review critique: the approved top 10 proposals (outcome, code changes, rationale, scoring). |
| `proposal-other-ideas-dataset-review.html` | The companion list of 22 further ideas and the source bibliography. |

The plan itself lives in **beads** (`bd ready`, `bd list`, `bd show <id>`).
`docs/html/proposals.html` is the pointer to both.
