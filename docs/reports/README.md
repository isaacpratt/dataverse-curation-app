# Historical reports

Dated reports kept for the record, outside the published Zensical site. They
describe a point in time; they are not maintained and they do not state the
current plan.

| Report | What it records |
| --- | --- |
| `proposal-top10-dataset-review.html` | The 2026-11 dataset-review critique: the approved top 10 proposals (outcome, code changes, rationale, scoring). |
| `proposal-other-ideas-dataset-review.html` | The companion list of 22 further ideas and the source bibliography. |
| `diataxis-audit.md` | The quadrant/template audit of the published Markdown pages (dv-uq6). The published proposal snapshots live in `docs/proposals/`, not here. |

The plan itself lives in **beads** (`bd ready`, `bd list`, `bd show <id>`).
`docs/explanation/design-records/index.md` is the pointer to the published
proposal snapshots; this folder keeps the older HTML reports for provenance.
